Compile SHVM_LZ_v3_figures_embedded.tex with pdflatex twice. It embeds the scenario plot numerically in PGFPlots and needs no external figure. The same plot is separately supplied as scenario_shapes.pdf/png. Run python scripts/compare_scenarios.py to regenerate the separate plot and numerical audit, then python scripts/embed_figure.py to regenerate the standalone TeX. Dependencies: Python 3, NumPy, SciPy, Matplotlib; LaTeX packages include pgfplots. Numerical surrogates are not the LZ detector likelihood.
